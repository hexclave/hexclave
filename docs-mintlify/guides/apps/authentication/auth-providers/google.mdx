This guide explains how to set up Google as an authentication provider with Hexclave. Google OAuth2 allows users to sign in to your application using their Google account.

<Info>
  For Development purposes, Hexclave uses shared keys for this provider. Shared keys are automatically created by Stack, but show Stack's logo on the OAuth sign-in page.
  You should replace these before you go into production.
</Info>

## Integration Steps

<Steps>
  <Step>
    ### Create a Google OAuth2 App

    1. Navigate to the [Google Cloud Console](https://console.cloud.google.com/).
    2. Create a new project or select an existing one.
    3. In the sidebar, navigate to **APIs & Services** > **Credentials**.
    4. Click **Create Credentials** and select **OAuth client ID**.
    5. Select **Web application** as the application type.
    6. Enter a name for your OAuth client.
    7. Under **Authorized redirect URIs**, add `https://api.hexclave.com/api/v1/auth/oauth/callback/google`
    8. Click **Create**.
    9. Save the **Client ID** and **Client Secret** that are displayed.
  </Step>

  <Step>
    ### Enable Google OAuth2 in Hexclave

    1. On the Hexclave dashboard, select **Auth Methods** in the left sidebar.
    2. Click **Add SSO Providers** and select **Google** as the provider.
    3. Set the **Client ID** and **Client Secret** you obtained from Google Cloud Console earlier.
  </Step>
</Steps>

## Native apps

Prefer the [Swift SDK](https://github.com/hexclave/swift-sdk-prerelease) (public beta). It opens Google through Hexclave and handles the callback:

```swift
try await stack.signInWithOAuth(provider: "google")
```

That uses the callback scheme `hexclave-mobile-oauth-url://`. If you call the REST API yourself:

1. `GET https://api.hexclave.com/api/v1/auth/oauth/authorize/google` with query `client_id` (project ID), `client_secret` (publishable client key), `redirect_uri`, `scope=legacy`, `state`, `grant_type=authorization_code`, `code_challenge` (S256), `code_challenge_method=S256`, `response_type=code`, and `type=authenticate`.
2. `POST https://api.hexclave.com/api/v1/auth/oauth/token` as `application/x-www-form-urlencoded` with `grant_type=authorization_code`, `code`, `redirect_uri`, `code_verifier`, `client_id`, and `client_secret`.

`scope=legacy` is Hexclave's OAuth-client scope, not a Google Cloud scope string.

OAuth-only users have `hasPassword === false`. To add a password later, enable password sign-in and call `user.setPassword({ password })` (or `POST /api/v1/auth/password/set`). Use `updatePassword` only when a password already exists.
